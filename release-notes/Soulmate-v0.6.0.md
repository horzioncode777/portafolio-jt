# Piano Soulmate 0.6.0 para Windows

Aplicación de escritorio para interpretar un piano desde un teclado MIDI, explorar instrumentos y grabar interpretaciones en WAV.

- Biblioteca de pianos y bancos de sonido integrados.
- Entrada MIDI y manejo del pedal de sustain.
- Controles de sonido, ambiente y efectos.
- Grabación de interpretaciones en formato WAV.

Descarga **Soulmate-Setup-0.6.0.exe** y sigue el instalador para Windows de 64 bits. No necesitas instalar Node.js para utilizar el programa.

Conecta tu teclado MIDI, abre Soulmate y selecciona el dispositivo en Ajustes. También puedes explorar la aplicación con el teclado del PC.
