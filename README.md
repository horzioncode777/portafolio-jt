# Portafolio de Juan Esteban Torres Delgado

Portafolio profesional Full Stack con proyectos de desarrollo web, escritorio y análisis de datos.

## Publicación en Vercel

Sitio estático HTML, CSS y JavaScript. La configuración de Vercel ejecuta `node build-pages.cjs && node prepare-vercel.cjs` y publica `vercel-public/`. No requiere dependencias npm.

El instalador de Piano Soulmate se distribuye mediante GitHub Releases; su URL se configura en `deployment-config.json`. El CV descargable usa la versión ATS. El formulario de contacto utiliza FormSubmit.

## Vista previa local

Ejecuta `python preview.py --serve` y abre http://127.0.0.1:4173/. En Windows también puedes ejecutar `Abrir portafolio.cmd`.
